# نيورا · NEURA

موقع تعليمي تفاعلي بتصميم **زجاجي (Glassmorphism)** يشرح الذكاء الاصطناعي والبرمجة في **٨ فصول تفاعلية**، بالعربي والإنجليزي، وصفحة واحدة بأسلوب العرض المتدرّج (بدون تنقّل بين صفحات).

> الهدف: الزائر ما يقرأش عن التقنية بس — **يلمسها**. كل فصل فيه تجربة بتشتغل فعلًا جوه المتصفح.

---

## التشغيل

```bash
npm install      # مرة واحدة
npm run dev      # سيرفر التطوير على http://localhost:5173
npm run build    # نسخة الإنتاج في مجلد dist/
npm run preview  # معاينة نسخة الإنتاج
```

المشروع **بدون أي مكتبة واجهات** (لا React ولا Vue) — HTML + CSS + JavaScript خام مع [Vite](https://vitejs.dev) كأداة بناء فقط.

## الفصول والتجارب التفاعلية

| # | الفصل | التجربة التفاعلية |
|---|-------|-------------------|
| ٠١ | الشبكات العصبية | شبكة عصبية حقيقية (2-6-5-4) بتتدرّب في متصفحك: تمرير أمامي وعكسي ونزول تدرّج من الصفر، مع خريطة قرار تفاعلية تقدر تسحب فيها نقاط البيانات |
| ٠٢ | التقطيع إلى وحدات | محلّل تقطيع (تقريب لـ BPE) بيشتغل على العربي والإنجليزي: بادئات ولواحق عربية، دمج الأزواج المتكررة، ورقم كل قطعة |
| ٠٣ | النماذج اللغوية | حساب أوزان الانتباه (QKᵀ + Softmax) لكل كلمة، ومولّد يحسب توزيع احتمالات للكلمة الجاية مع شريط «درجة الحرارة» |
| ٠٤ | كيف تتعلّم الآلة | تدريب حقيقي: منحنى B-spline مع نزول تدرّج ومُحسِّن زخم، وتعرض الفرق بين الحفظ (Overfitting) والتعميم |
| ٠٥ | البرمجة | مقارنة ٦ لغات برمجة + محرّر صغير بينفّذ JavaScript حقيقي ويلوّن الكود ويعرض الأخطاء |
| ٠٦ | هندسة الأوامر | مقياس جودة فوري بيقرأ أمرك ويقيّمه على ٦ معايير، وبيعيد صياغته محسّنًا |
| ٠٧ | خريطة التعلّم | خريطة ٩ أشهر تفاعلية مع حفظ التقدّم في المتصفح |
| ٠٨ | الأخلاقيات والأمان | مواقف واقعية باختيارات متعددة وتفسير لكل قرار |

بعد الفصول: **اختبار سريع** (٥ أسئلة مع تفسير كل إجابة وحفظ أفضل نتيجة) و**أسئلة شائعة**.

## المزايا

- **زجاجية كاملة**: طبقات `backdrop-filter`، حد متدرّج متحرك، ولمعة تتبع المؤشر على البطاقات.
- **خلفية حية**: ٤ هالات متدرّجة متحركة + شبكة خطوط + غبار رقمي (Canvas) بيتفاعل مع المؤشر.
- **وضعان**: غامق وفاتح، مع حفظ الاختيار.
- **لغتان**: عربي (RTL) وإنجليزي (LTR) بزر تبديل فوري — مع الحفاظ على موضع القراءة.
- **تحرّك محترم**: كل الحركات بتتوقف لما العنصر يخرج من الشاشة، وبتُلغى بالكامل مع `prefers-reduced-motion`.
- **وصول**: تخطّي للمحتوى، تركيز واضح (`focus-visible`)، عناصر دلالية، وبديل `noscript`.
- **بدون تتبّع**: كل حاجة (التدريب، التقطيع، التقدّم، أفضل نتيجة) بتشتغل محليًا — مفيش إرسال لأي بيانات ولا مكتبات طرف ثالث.

## بنية المشروع

```
index.html                 # الهيكل + وصفات SEO/OG
public/
  favicon.svg
  images/og-cover.jpg      # صورة المشاركة على السوشيال
src/
  main.js                  # نقطة التشغيل: البناء، الحالة، اللغة، المظهر
  core/                    # dom · state · i18n · scroll · dust · toast
  data/                    # site · strings · chapters · quiz · faq
  sections/                # hero · chapters · quiz · faq · footer
  widgets/                 # neural · tokenizer · attention · train · code · prompt · map · ethics · orb
  styles/                  # tokens · layout · widgets
```

### إضافة فصل جديد

1. ضيف الكائن في `src/data/chapters.js` (نسختين: `ar` و`en`) مع `id` و`num` و`widget`.
2. لو محتاج تجربة جديدة: اعمل ملف في `src/widgets/` يصدّر `mount(host, { chapter, lang, t })` وارجّع دالة تنظيف، وسجّله في `src/widgets/index.js`.
3. الفصل يظهر تلقائيًا في الصفحة والتنقل والسكة الجانبية وشريط المواضيع.

## ملاحظات تقنية

- كل التجارب مكتوبة يدويًا: `neural.js` بيعمل backprop بنفسه، و`train.js` بيحسب مشتقات دالة الخسارة على أساسيات B-spline.
- مفيش خطوط من CDN: كل الخطوط (Readex Pro · IBM Plex Sans Arabic · Sora · JetBrains Mono) مضمّنة عبر `@fontsource` وبتُبنى مع الموقع — الموقع يشتغل حتى بدون إنترنت.
- `vite.config.js` مضبوط على `host: true` و`allowedHosts: true` عشان المعاينة الحيّة تشتغل من أي نطاق.
- حالة المستخدم محفوظة في `localStorage` تحت المفتاح `neura.state.v1` (لغة، مظهر، تقدّم الخريطة، أفضل نتيجة).
